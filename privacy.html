Spatial Canvas 隐私政策

更新日期：2026-11-19

Spatial Canvas 是一个本地优先的浏览器扩展。扩展记录页面网址、标题、图标、页面之间的跳转关系，以及用户主动添加的笔记、标签、分组和布局。

数据存储

数据保存在用户浏览器的本地扩展存储中。项目没有自建服务端，不出售、不共享、不用于广告或用户画像。扩展不读取网页正文、Cookie、表单内容或其他浏览历史。

记录控制

用户首次开启记录前会看到说明。用户可以暂停记录或排除网站。隐私窗口、浏览器内部页面和不可追踪页面不会进入画布。

导出和删除

用户可以导出 JSON 备份，也可以在扩展内清理或删除记录。卸载扩展会由浏览器删除本地扩展数据；卸载前请先导出需要保留的内容。

第三方服务

当前版本不调用远程 AI 或其他第三方数据服务。未来如增加用户自带 API 的整理功能，会在发送前明确显示发送范围，并由用户自行配置服务商。

联系

请通过发布仓库的 Issue 反馈隐私问题或删除请求。
